# BarangayLink

A web-based document request and facility reservation system for a barangay.

## About
BarangayLink lets residents request barangay documents and reserve barangay facilities online, and lets barangay staff review and manage those requests in one place.

## Features
- Resident registration and login
- ID verification through the Profile tab
- Document requests with status tracking (Pending, Processing, Ready for Pickup, Completed, Denied, Cancelled)
- Facility reservations with conflict checking
- In-app notifications
- Admin dashboard, account review, request and reservation management
- Admin management of document types and facilities

## Tech stack
- Frontend: HTML5, CSS3, JavaScript ES6+, Bootstrap 5
- Backend: Node.js with Express (or PHP, to be finalized)
- Database: MySQL/MariaDB
